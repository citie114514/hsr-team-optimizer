## 二、AI 干了什么

工具：**GPT-6 Astra**，订阅约 3000 元人民币。

1. **自己找情报**。模型用内置浏览器翻米游社 4.5 攻略、B 站「立界开篇 星启 呼雷 云璃 千冶刃」
   相关视频，甚至**自己拖进度条**看攻略视频。
2. **读账号**。截图识别角色、星魂、遗器。
3. **第一轮优化**：把「水鸟」换到第一队。→ **分数没有明显变化。**
4. **出现「经典的外行指导内行」**：AI 给了错建议（UP 主原话）。
5. **提出两个方向**：调低配置、用溢出的战力救济其他两队。
6. **建议抛弃 11 云璃**，让千冶刃打主 C。
7. **第三队换阵容** → 第三队达到 31,000（该节点门槛 30,000）。
8. **遗器单变量实验**（这是全片最有价值的部分）：

   | 改动 | 已验证的结果 | 能说明什么 |
   |---|---|---|
   | 刃：速度鞋/原手 → 生命鞋/补速手 | 战前生命约 6,437.7，速度 121.1；同条件固定动作伤害约 **+22.51%** | 更高单次输出值得实测；降速是否关键行动仍需录像 |
   | 银狼：原头 → 6.6 速新头 | 战前速度 183.932 → 190.532；固定动作伤害约 **+1.69%** | 主要价值含速度，不能只读伤害百分比 |
   | 艾光：原速度鞋 → 新速度鞋 | 保持速度主词条；固定动作伤害约 **+8.03%** | 属性补强，仍不能换算成分数 |
   | 四件辅助借装 + 加拉赫龙骨球绳 | 新扫描确认实际穿戴，十二人装备实例无冲突 | 这是组合改动，不是严格的单变量测试 |

9. **第 2 天**：模拟迭代 **33 次**，流程持续优化。
10. **被用户纠正复盘规范**（关键转折）：
    - 用户原话：「我在测试这套的分数了，同时我觉得你看录像的手法有些粗糙，
      我觉得应该从**左边的行动轴和回合数、行动值**来判断时机，而不是视频的时间长度」
    - AI 回应：「你说得对。视频时间只适合定位画面；判断启动、出手次数和循环快慢，
      应该以左侧行动轴、剩余轮次和行动值为依据。我会把这点写进复盘规范，
      尤其避免用动画长短来判断刃换生命鞋后的循环表现。」
11. **第 3 天**：动用 **自塑尘脂 25 个** 合成遗器（「博识尊也架不住我手黑」）。
12. **产出「新合成目标与验收」表**，明确写了「以下为目标词条，**未合成，不是库存已有的成功成品**」：

    | 优先级 | 部位 | 目标主词条 | 量化意义 |
    |---|---|---|---|
    | 1 | 二队 银狼「零号关卡朋克洛德」球 | 生命/防御主优先；速度至少 6.6，继续争取 8-9.2，兼顾暴伤/暴击 | 现球 0 速，6.6 速球使战前 190.532→197.132；9.2 速球 →199.732 |
    | 2 | 三队 缇宝「晨昏交界的翔鹰」暴击衣 | 速度约 6.9、暴伤约 19.4%、生命约 7.8%，其余词条不限 | 相对现衣 2.6 速，整体 142.032→146.332；示意生命/双暴，同条件单次伤害模型约 +4%，并改善循环，不是三队分数 +4% |
    | 3 | 二队 艾光「应天涉远的卜者」手 | 速度 6.6 以上，兼顾约 3.2% 暴伤、1.3% 暴击 | 保住卜者 160、充能绳；先做手，不重复做 22% 暴速的速度鞋 |

13. **结果**：
    - 中途：最高积分 93,880（节点一 40,000 / 节点二 29,640 / 节点三 24,240）
    - 最终：节点一 40,000 / 节点二 32,360 / 节点三 27,680 = **100,040 分，12/12 满星**

## 三、从案例里提炼出的规则

### ✅ 真正起作用的部分

1. **单变量 + 实测**。那四行遗器实验表是全片价值最高的东西：一次只改一件，改完记录
   具体数值（战前生命 6,437.7、速度 121.1、伤害 +22.51%）。
2. **量化意义**。每条遗器目标都写清楚「拿到之后哪个数值从多少变成多少」。
3. **库存免责声明**。「未合成，不是库存已有的成功成品」—— 这一句避免了用户误解。
4. **判据来自游戏内部**。行动轴 / 剩余轮次 / 行动值，而不是视频时长。
5. **资源账本**。自塑尘脂 25 个、33 次模拟迭代，都记了。
6. **明确的停止点**。满星即停。

### ❌ 走过的弯路

1. **判据用代理指标**。AI 一开始拿视频时间长度判断「循环变快没有」，被用户纠正。
   → 本 skill 硬规则第 3 条。
2. **第一轮改动（水鸟换第一队）无收益**。改动前没有先建基线、没有先算预期收益。
   → 本 skill 的 P2 + P3 排序。
3. **「外行指导内行」**。AI 给了不符合游戏机制的建议。
   → 先做 P0 情报、拿到机制表再提改动。
4. **成本失控**。678M tokens / $427，且大部分开销来自反复喂录像。
   → 本 skill 的三层路由 + token 纪律，目标 ≈ $28。

### 📊 收益曲线

```
79,520  ──(水鸟换队，无效)──  79,520
        ──(溢出战力救济两队)──  93,880
        ──(遗器单变量 ×4 + 自塑尘脂 25)──  100,040  ✅ 满星
```

从 79,520 到 100,040 是 **+25.8%**。其中**换配队**贡献了绝大部分（+18%），
**遗器微调**贡献了剩下的（+7% 量级）。

> 这条曲线本身就是一条策略：**先动配队（成本低、收益大），配队收敛了再动遗器（成本高、收益小）。**
