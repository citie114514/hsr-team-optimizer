# 七阶段详解

每一阶段都写明：**输入 / 动作 / 产出 / 判断口径 / 常见坑**。

---

## P0 情报

**输入**：模式名 + 期数。
**动作**：抓本期节点机制、增益/减益、星级门槛、当期主流配队。
来源优先级：米游社攻略帖 > B 站攻略视频（看简介/专栏文字优先，别真去扒视频）> 其他。

**产出**：一张表。

| 节点 | 敌方 | 节点机制 | 星级门槛 | 主流配队 |
|---|---|---|---|---|
| 节点一 | | | 45000 / 60000 / 75000 / 90000 / 99000 | |
| 节点二 | | | | |
| 节点三 | | | | |

**判断口径**：门槛必须是「每个节点各自要多少分才能拿几颗星」，不是总分。
总分门槛可以反推，但决策要用节点门槛。

**常见坑**：
- 把上一期的数值当本期用 → 版本号必须写在表头。
- 只抄配队不看机制 → 机制决定「为什么这套配队能过」，没有机制就没法在缺角色时替换。

---

## P1 盘点

**输入**：账号截图或手输清单。
**动作**：把角色 / 星魂 / 等级 / 光锥 / 遗器（部位+主词条+副词条）整理成结构化清单。
**产出**：名册表 + 「可用队伍池」。

**判断口径**：一个角色算「可用」需要同时满足
1. 等级 80（或该模式上限）
2. 光锥有成型替代
3. 遗器主词条对，且速度/生命/暴伤等关键副词条达到档位
4. 星魂不拖后腿

不满足的写进「不可用」并注明缺什么 —— **这是 P5 遗器清单的输入**。

**常见坑**：
- 把「有这个人」当成「能用这个人」。视频里的 UP 主有一整页角色，但真正成形的队伍只有三支。
- 不记录速度。速度是崩铁里最容易一条副词条改变整轮循环的数值，必须逐个角色记。

---

## P2 基线

**输入**：可用队伍池。
**动作**：用**现有**队伍（不要先优化）各打一轮，记录每节点分与总分。
**产出**：账本第 0 轮。

**判断口径**：
- 全自动战斗（如果目标是自动），手动成绩不能当基线。
- 记录的不只是分数，还有行动轴（每个角色第一次出手在哪个轮次）、战技点曲线、谁先倒。
  这些是 P3 的素材，只有分数就无从下手。

**常见坑**：
- 跳过基线直接改。没有基线，后面每一轮的增益都无法计算。
- 基线只打一次。**自动战斗有随机性**，基线最好打 2-3 次取最高值，否则后面会把随机波动当成改动收益。

---

## P3 迭代（核心）

**输入**：基线 + P0 机制表 + P1 名册。
**动作**：

1. 列候选改动。来源有三类：
   - **换人**：把 A 队的人挪给 B 队（视频里「把水鸟换到第一队」「用溢出的战力救济其他两队」就是这个）
   - **换遗器**：改一个主词条（速度鞋 ↔ 生命鞋）、换一个散件
   - **换光锥 / 调速度档位**
2. 每个候选估一个「预期收益 ÷ 改动成本」：成本 = 需要花多少体力/自塑尘脂/是否要重练。
3. **一次只上一个**，打完记账。

**产出**：账本 N 行，每行含【改动 / 验证结果 / 能说明什么】。

**判断口径**（这是整个 skill 最关键的一段）：

| 想判断 | 看什么 | 不要看 |
|---|---|---|
| 出手快不快 | 左侧行动轴、剩余轮次、行动值 | 视频时长 |
| 循环通不通 | 战技点最低点、充能是否溢出、buff 覆盖率 | 「感觉顺畅」 |
| 伤害高不高 | 同条件固定动作的伤害数字 | 单次暴击大数字 |
| 阵容强不强 | 节点分、总分 | 战力/评分面板 |

> 真实案例里的教训：AI 一开始用「视频时间长度」判断「换生命鞋后循环是否变快」，
> 被用户纠正为「看左侧行动轴、剩余轮次和行动值」。这条被写进了复盘规范。
> 凡是代理指标（时长、战力、观感），一律不用。

**常见坑**：
- **一次改两件**。比如同时换人和换遗器，分数涨了也不知道是谁的功劳。
- **不记假设**。只记改动不记预期，事后无法判断模型的世界模型对不对。
- **把随机波动当收益**。自动战斗同一配置分数会浮动，增益 < 1% 的轮次应当标注为「噪声内」。

---

## P4 收敛

**输入**：账本。
**动作**：停止条件满足就停。
**产出**：最终配队表 + 停止原因。

**停止条件**（满足任一）：
1. 总分 ≥ 满星线 → 停，把资源留给下一期
2. 连续 3 轮增益 < 1%（噪声内）→ 停，说明瓶颈不在配队而在练度，转 P5
3. 可用资源（体力/自塑尘脂）耗尽 → 停，输出当前最优 + 待办清单

**常见坑**：
- 满星后继续优化。视频里满星是 100,040，再往上没有任何收益 —— 除了烧钱。
- 收益递减时不换赛道。配队收敛了就该去刷遗器，而不是继续换人。

---

## P5 遗器清单

**输入**：P1 的「不可用」清单 + P3 中暴露的数值缺口。
**动作**：按优先级输出合成/刷取目标。
**产出**：见 `templates/relic-shopping-list.md`。

**判断口径**：每条目标必须包含四要素，缺一不可：

```
部位：<角色>「<遗器套装>」<部位>
目标主词条：<主词条>
副词条门槛：<至少 X，争取 Y，兼顾 Z>
量化意义：<拿到之后哪个数值从多少变成多少，影响什么>
```

并且必须显式写：**以上均为目标词条，未合成，不是库存已有的成品。**

**常见坑**：
- 把目标写成已获得。用户会以为你已经帮他配好了。
- 不给量化意义。没有量化意义的目标等于「多刷点」，无法执行。
- 优先级不排。资源有限时必须有 P1/P2/P3。

---

## P6 复盘规范

**输入**：本期所有踩坑记录。
**动作**：把「这次错了什么、为什么错、下次怎么判」写进一份可复用的规范文件。
**产出**：追加条目，例如：

```
## 判据规范
- 判断循环快慢用行动轴/剩余轮次/行动值，不用视频时长。
- 判断伤害用同条件固定动作，不用单次暴击峰值。
- 自动战斗存在随机性，增益 < 1% 视为噪声，需重复验证。

## 资源规范
- 自塑尘脂只投在 P1 目标上。
- 主词条不对的遗器不进盘子。
```

下一期开局时先读这份规范。这是把「3 天弯路」压缩成「第 1 天就避坑」的唯一办法。
